Development of the AquaGuard platform started from the existing GeoTwin codebase. The project was renamed, paths and environment names were updated, and the two pilot municipalities were set to Pangaion (Greece) and Limanu (Romania).

The platform’s subject is flood resilience. Weather, soil moisture, and flood-risk data replace the previous air-quality scope, and the dashboard, Keycloak realms, and context-broker namespace follow the new name and the two municipalities.

The code lives in the AquaGuard repository linked above. This repository records the pilot’s public progress from that starting point.
