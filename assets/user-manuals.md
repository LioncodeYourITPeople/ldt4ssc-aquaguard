# User manuals (English, Greek, Romanian)

Everyday guides for municipal staff and citizens using AquaGuard.

## Purpose

Explain the map, what-if scenarios, personal data, and how the flood models are used, in the languages of the two pilot municipalities and in English.

## What it contains

Each language has the same set of guides:

- Getting started
- Reading the map
- Scenario planning
- Data and privacy
- AI transparency

The same pages are served from the dashboard at `/help`.
